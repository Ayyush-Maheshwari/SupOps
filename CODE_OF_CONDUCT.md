# Code of conduct

Be respectful and constructive. Disagree about ideas, not people. No harassment, insults or
discrimination, in issues, pull requests or anywhere else connected to the project.

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report unacceptable behaviour privately to the maintainer through GitHub; reports are handled
confidentially. Maintainers may remove comments or contributions, or block people, who break it.
